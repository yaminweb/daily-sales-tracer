🔒 Google Sheets Setup Guide

  1. Open your Google Sheet → Extensions → Apps Script
  2. Delete all existing code, paste the full google-apps-script.gs contents
  3. Press Ctrl+S to save
  4. Click Deploy → New deployment
  5. Click the gear icon ⚙ → Web app
  6. Execute as: Me  |  Who has access: Anyone
  7. Click Deploy → Authorise access → Allow
  8. Copy the Web App URL → paste above → Save URL
  9. Important: After any edits, always deploy as a New version
